**Проект "Вишлист":** создание списков желаний и подарков, которыми можно делиться по ссылке с друзьями

**Стек:** Nuxt 4, Vue 3, TypeScript, Nuxt UI, Tailwind CSS, ESLint.

**Фичи проекта:**
1. вход через GitHub
2. бронирование подарков
3. загрузка фото
4. возможность делиться списком по ссылке
5. возможность просматривать вишлист
